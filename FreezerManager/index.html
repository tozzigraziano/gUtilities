ℹ️ Informazioni

Questa applicazione ti aiuta a gestire il contenuto del congelatore tracciando prodotti, date di inserimento e durate di conservazione basate sulle linee guida USDA FoodKeeper. I dati vengono salvati localmente nel browser (IndexedDB) ma puoi anche configurare una connessione a MariaDB per sincronizzare tra dispositivi.

Configurazione Database MariaDB

Stato Connessione Disconnesso

Configurare una connessione a MariaDB richiede un backend server (API REST) per motivi di sicurezza. I dati sono attualmente salvati localmente nel browser.

Configurazione Backend API

Istruzioni per Backend

Per connettere questa applicazione a MariaDB, è necessario creare un backend server Node.js o PHP che esponga API REST per:

• GET /items - Recuperare tutti i prodotti
• POST /items - Aggiungere un nuovo prodotto
• PUT /items/:id - Aggiornare un prodotto
• DELETE /items/:id - Eliminare un prodotto

Schema Database MariaDB suggerito:
CREATE TABLE freezer_items (
  id INT AUTO_INCREMENT PRIMARY KEY,
  product_type VARCHAR(50) NOT NULL,
  product_name VARCHAR(100) NOT NULL,
  insert_date DATE NOT NULL,
  quantity VARCHAR(50),
  storage_duration INT NOT NULL,
  notes TEXT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
